# 📊 Sales Performance Dashboard – Power BI

## 🔎 Project Overview
This project analyzes sales performance across countries, products, and time periods using Power BI.

The dashboard provides insights into:
- Country-wise sales distribution
- Product-wise shipment performance
- Monthly revenue trends
- Year-over-year comparison

---

## 🛠 Tools Used
- Power BI
- Microsoft Excel
- Data Visualization
- Data Cleaning

---

## 📈 Key Insights

1. Australia and Canada have the highest box shipments.
2. Dark Bites and Smooth Silky Salt are top-performing products.
3. Sales fluctuated significantly between January and July.
4. Waterfall analysis shows product-level contribution to revenue changes.

## 🎯 Business Recommendation
- Focus marketing efforts on high-performing countries.
- Increase inventory for top-performing products.
- Investigate revenue dip periods for performance improvement.
